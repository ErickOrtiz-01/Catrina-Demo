# La Catrina of Argenta — Demo Website

This is a concept restaurant website built as a sales/demo piece for **La Catrina of Argenta**.

## Theme update
This version was redesigned to feel **more "Catrina"** by adding:
- a stylized floral **Catrina/calavera heroine** in the hero section
- richer marigold / rose / emerald colors
- more decorative cantina personality while keeping the site clean and pitch-ready

## Files
- `index.html`
- `styles.css`
- `script.js`

## How to use
1. Open `index.html` in your browser to preview locally.
2. Upload the files to a GitHub repository.
3. Turn on **GitHub Pages** in repository settings.
4. Share the live link when pitching the demo.

## Notes
- This is a **concept website** and includes a disclaimer saying it is not the official site.
- Menu items, pricing, and business details should be confirmed before using it as a final client website.
- You can later swap the illustration for the restaurant's real logo or photography if they want that direction.
